# Lab: Install the Virtual Machine Lab Environment
* **Role:** Junior Network Automation Engineer & DevNet Student.
* **Task:** Document the installation, GUI exploration, and account setup for the Cisco DevNet Associate (DEVASC) virtual machine environment[cite: 8].
Context & Technical Requirements
* **Environment:** Ubuntu 20.04 DEVASC Virtual Machine running on Oracle VirtualBox, accessed via SSH from a Windows host.
* **Prerequisites:** Host computer with virtualization enabled, minimum 4 GB RAM, and 15 GB free disk space[cite: 8].

## Execution Steps & Discovery

### Part 1: Virtualization & VM Import
* Downloaded and installed Oracle VirtualBox on the host machine[cite: 8].
* Imported the official Cisco DEVASC VM appliance via *File > Import Appliance* in VirtualBox[cite: 8].

### Part 2: GUI & Tool Exploration
* Booted the Ubuntu image and accepted the Cisco Packet Tracer EULA using keyboard navigation (`<OK>` and `<I Agree>`)[cite: 9].
* Explored core developer tools pre-installed in the environment: Terminal, VS Code, Packet Tracer, Chromium Browser, and Postman[cite: 9].

### Part 3: Account Creation & Lab Setup
* **DevNet Account:** Created and configured via `developer.cisco.com` using Cisco ID integration[cite: 10].
* **GitHub Account:** Established (`mlunadevops`) to manage version control and code portfolios[cite: 10].
* **Webex Account:** Registered for collaboration and communication across course labs[cite: 10].

### Part 4: VM Management & Lifecycle
* Practiced shutting down and saving machine states safely via GUI and CLI (`sudo shutdown -h now`)[cite: 10].

## Value-Add & Next Steps
* Environment fully operational and integrated with a secure Git version control workflow via SSH and Personal Access Tokens (PAT).
